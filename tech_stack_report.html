🏗 Architecture Overview

Design Patterns & Approach

Frontend Architecture:Single-Page Application (SPA) — single index.html with JS-driven page routing
Authentication:Client-side RBAC via AuthManager class (SHA-256 hashing, localStorage)
AI Integration:Agentic RAG pattern — live data retrieval → context building → Groq reasoning
API Design:RESTful endpoints with FastAPI auto-documentation (OpenAPI/Swagger)
Data Flow:Supabase ↔ Frontend (JS SDK) + Supabase ↔ Backend (REST) ↔ Groq AI
Deployment:Local dev server (frontend) + Uvicorn on port 8000 (backend)

AI Assistant Data Flow

User Query→ agent.js→ FastAPI /ask-agent→ Supabase (live data)→ Groq AI→ Response
