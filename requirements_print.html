2. Data Collection Methods

⚠️ IMPORTANT — Minimum Data Requirements

You need at least 200-500+ records for meaningful ML predictions. For deep learning, aim for 1000+ records or use data augmentation techniques (SMOTE, GANs).

Method Description Priority
University Records Academic data from the registrar / admin office 🔴 Must Have
Alumni Surveys Google Forms / Microsoft Forms for career data 🔴 Must Have
LinkedIn Scraping Extract current positions (with consent) 🟡 Nice to Have
Department Records Course catalogs, skill mappings per course 🔴 Must Have
Employer Feedback Partner companies hiring your alumni 🟢 Optional
Synthetic Data SMOTE / GAN-generated for model training 🟡 Nice to Have

3. ML/DL Model Requirements

3.1 Prediction Tasks

Task Type Input Features Output
Employability Score Regression Skills, CGPA, Projects, Certs Score (0-100%)
Job Placement Prediction Classification Academic + Skill data Employed / Unemployed
Salary Range Prediction Multi-class Classification All features Salary bracket
Time to Employment Regression Skills, CGPA, Internships Months
Industry Sector Prediction Multi-class Classification Specialization, Skills Industry type
Job Role Recommendation Recommendation Skill profile Top-5 roles

3.2 Recommended Models

Machine Learning Models

Model Use Case Why
Random Forest Employability Classification Handles mixed features, interpretable
XGBoost / LightGBM Salary & Employability Prediction High accuracy on tabular data
Logistic Regression Baseline binary classification Simple, interpretable baseline
SVM Small dataset classification Works well with limited data
K-Nearest Neighbors Job role matching Similarity-based recommendations

Deep Learning Models

Model Use Case Why
Feed-Forward Neural Network (ANN) Employability score prediction Captures non-linear patterns
LSTM / GRU Career trajectory prediction Sequential semester data analysis
Autoencoders Skill gap analysis Dimensionality reduction & anomaly detection
Transformer-based (BERT) Resume / feedback text analysis NLP on alumni feedback text

3.3 Feature Engineering Requirements

These are the key derived features that should be engineered from raw student data before feeding into models:

Key Derived Features: ├── skill_diversity_score → Count of unique skill categories ├── academic_consistency → Variance of semester GPAs ├── practical_exposure → (Internships + Projects) weighted score ├── certification_value → Weighted sum of certifications ├── research_intensity → Publications / Years of study ├── program_completion_rate → Credits completed / Required credits ├── network_strength → Extracurricular + Online presence score └── industry_alignment → Skill match with industry demands

7. Data Privacy & Compliance

⚠️ WARNING — Personal Data Handling

Since you're handling personal data of students and alumni, you must ensure compliance with data protection standards:

  • Written consent from alumni for data collection
  • Data anonymization for model training
  • Secure storage with encryption
  • Role-based access control on the dashboard
  • Compliance with university data policies

8. Minimum Viable Product (MVP) Checklist

Complete these tasks to deliver a functional MVP of the system:

  • Collect academic data for at least 200 students across all programs
  • Design and distribute alumni survey form
  • Clean and preprocess collected data
  • Perform exploratory data analysis (EDA)
  • Engineer features from raw data
  • Train and compare at least 3 ML models
  • Train at least 1 DL model (ANN / LSTM)
  • Build REST API for model predictions
  • Design and develop the web dashboard
  • Integrate prediction API with dashboard
  • Test with real alumni data
  • Document the entire system
